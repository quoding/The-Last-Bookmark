# 2026-09-07 작업 기록 (Claude)

## 담당 범위
`backend/` 전체. CLAUDE.md 11.1의 작업 순서를 따라 진행했다. `frontend/`는 건드리지 않음(Codex 작업 영역).

## 1. DB 스키마와 장면 엔진
- `backend/app/models.py`: sessions, messages, scene_events, confirmed_events, card, images, image_jobs, requests 8개 테이블.
  내부 수치(trust/closeness/tension)는 sessions 컬럼에만 두고 schemas.py(API 응답)에는 절대 포함하지 않음.
- `backend/alembic/`: 초기 마이그레이션(`edb239063726`) + card.decided 컬럼 추가(`d62ec2df6fc2`). 실제 postgres에 up/down 양방향 검증.
- `backend/app/engine/scene.py`: 턴 번호 → 이야기 시각·장면을 돌려주는 순수 함수. ui-spec.md 6장 표를 `tests/test_scene_engine.py`로 먼저 고정(3·6·9턴에서만 전환).
- `docker-compose.yml`: postgres 16 + api 서비스.

## 2. 인증과 회차
- `backend/app/auth.py`: 초대 코드는 해시로만 비교(INVITE_CODE_HASHES), code_id를 담은 JWT 발급.
- `backend/app/api/sessions.py`: 회차 생성/목록/이어하기를 코드별로 분리 저장. IMAGE_BUDGET_SESSIONS 초과 시 생성 차단.
- 초상화 재생성 최대 2회 제한, 실패로 인한 재시도는 횟수를 소모하지 않음.

## 3. 프리셋과 이미지
- `backend/app/images/presets.py`: CLAUDE.md 7.2 PRESETS를 상수로 그대로 이식. 번역 호출 없음(테스트로 결정성 검증).
- `backend/app/images/prompts.py`: STYLE+CHARACTER/REFERENCE+SCENE+NEGATIVE 3~4단 구조, SCENE_PROMPTS, 엔딩 슬롯 템플릿.
- `backend/app/images/openai_images.py`, `service.py`: ImageGenerator 인터페이스로 실제 호출 분리(테스트에서 목 대체 가능). 생성 즉시 storage/에 저장 후 DB에 경로 기록.
- 회차 시작 시 장면1은 동기 생성, 장면2~4는 BackgroundTasks로 백그라운드 생성(큐 없이 image_jobs 상태 테이블만 사용).

## 4~5. LLM과 턴 처리
- `backend/app/llm/prompts.py`: story.md 12장 YAML(persona/scenario)을 상수로 그대로 옮김. 8.4의 5개 요소(페르소나/장면 브리핑/확정 상태/최근 대화/금지사항) 순서로 조립.
- `backend/app/llm/contracts.py`, `client.py`: 1턴 1회 호출. 구조화 출력 검증 실패 시 최대 2회 재시도(턴 미소비), 최종 실패 시 reply만 살리고 proposed_events는 빈 배열로 강등.
- `backend/app/engine/state.py`: proposed_events는 제안일 뿐이며, 허용 목록(APPLIERS)에 있고 현재 상태에서 전제조건이 맞는 것만 확정. 사용자가 세계 상태를 직접 선언해도(예: "우리는 이미 사귀는 사이") 허용 목록 밖이면 무시됨 — story.md 13장 경로 E 대응.
- `backend/app/api/turns.py`: request_id 멱등 처리, 3·6·9턴 전환, 12턴 완료 시 서버가 직접 door_locked 확정 + 엔딩 생성 트리거.

## 6. 카드
- `backend/app/api/card.py`: '이 문장으로 남기기'/'빈 채로 두기'만 턴 소비. 원문 그대로 저장(교정·요약 없음), 최대 80자(보이는 문자 단위) 검증, 공백만 있는 입력 거부.

## 7. 엔딩
- `backend/app/engine/ending.py`: evidence의 quote는 DB 원문 그대로(LLM이 다시 쓰지 않음). 엔딩 이미지 슬롯(location/posture/expression/props/distance)은 미리 정의된 영문 조각 중 확정된 상태와 일치하는 것만 선택.
- `backend/app/api/end.py`: 메뉴 조기 종료. 작별 대사를 새로 만들지 않고 현재까지 기록만으로 엔딩 생성, 문 잠금은 확정하지 않음.
- `backend/app/api/ending.py`: 엔딩 조회, 엔딩 이미지 재생성.

## 8~10. 이미지 연동, 회차 목록, 배포
- BackgroundTasks + image_jobs 상태 테이블로 비동기 처리(큐 없음). 재진입 시 상태 복원, 같은 이미지 중복 생성 방지.
- `GET /api/sessions/{id}`로 회차 상태·메시지·이미지 복원.
- `backend/Dockerfile` 빌드 검증 완료.
